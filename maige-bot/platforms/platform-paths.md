# 平台路径详解（2026.10 调研）

## 路径对比

| | 星野智能体 | Agent Expert 2.0 | MaxClaw / MaxHermes |
|---|---|---|---|
| 形态 | C 端人格化角色 | 技能型专家 Agent | 云端 7×24 IM bot |
| 流量来源 | 星野社区信息流 | Expert 市场 | 你自己的 IM 群 |
| 多模态 | 语音/图片/视频交互 | 图片、视频生成内置工具 | 图片、视频生成内置工具 |
| 变现 | 星念分成（2%） | 创作者定价分成（将上线） | 订阅制（平台收） |
| 门槛 | App 内捏崽，零代码 | 自然语言描述，零代码 | 订阅会员，配置渠道 |
| 类似 Grok 程度 | ★★★★★ | ★★☆ | ★★★★ |

**结论：星野主战场（人格 + 社区流量），Expert 副战场（技能 + 分成），MaxClaw 远期（IM 群聊形态）。**

---

## 路径一：星野智能体（P0 落地）

1. 下载星野 App（iOS/Android/鸿蒙，暂无 Web 端）→ 手机号/微信登录
2. 进入「创作中心」→「捏崽」入口
3. 按项目资产填写：
   - 形象：`assets/avatar-prompts.md` 生成/上传
   - 人设：`persona/persona-v1.md` 的背景故事、性格关键词
   - 对话风格/提示词：`prompts/system-prompt.md`
   - 开场白：同上文件 3 选 1
   - 音色：5 种音色混合，清亮青年为主 + 20% 低沉
4. 提交审核（注意：不通过可看「智能体不通过原因自查」）
5. 审核通过后编辑页可切换底层模型调对话效果

### 注意事项
- 合规：平台曾被通报隐私问题、2026.7 起未成年人模式收紧——人设避免暧昧向设定
- 已知短板：偶发"吃设定"，用「事件簿」手动固化关键记忆
- 星念抽卡质量与互动深度挂钩，前 20 轮对话质量很重要

## 路径二：Agent Expert 2.0（P2）

1. 打开 agent.minimaxi.com/experts
2. 自然语言描述创建（例："做一个专家，把用户的一句话变成短视频分镜脚本并生成视频"）
3. 用免费 15 轮调试额度校准输出格式
4. 关注创作者定价分成上线，早期上架卡位

## 路径三：MaxClaw / MaxHermes（P3）

1. agent.minimax.io → MaxClaw 入口（需 MiniMax Agent 基础版订阅）
2. 创建 bot 人设（支持自定义人格）
3. 绑定 IM 渠道：飞书 / 钉钉 / Telegram / Discord / Slack / WhatsApp
4. 内置图片/视频生成工具，无需接第三方 API
5. MaxHermes 差异：自我进化 Skills（任务后自动沉淀技能文档），适合长期养成

> 若届时想做"@bot 就回"的群聊 Grok 体验，这条是官方最短路径，
> 且 MaxClaw 用户后续可一键迁移人设到 MaxHermes。
