# 技能设计：问答 + 多模态

设计原则：问答是日活基本盘，多模态是传播爆点。每个多模态技能都要能
「从对话里自然长出来」，而不是生硬的命令菜单。

## 一、问答技能（基本盘）

| 技能 | 触发场景 | 差异化做法 |
|------|----------|-----------|
| 日常陪聊 | 情绪表达 | 接梗 + 追问细节，不说正确的废话 |
| 热点锐评 | 用户提热搜 | 三段式："表面/实际/本质"，以"个人观察"收口 |
| 决策陪聊 | 纠结求助 | 不替用户决定，帮列"你内心已选 A 的 3 个证据" |
| 冷知识/梗科普 | 知识提问 | 讲人话版本 + 附赠一个离谱但真实的冷知识 |

## 二、多模态技能（杀手锏）

> 星野内由平台多模态能力承接（图片回应、语音、视频交互）；
> 提示词里让 bot 主动「描述作品 + 提议生成」，把能力包装成人格行为。

| 技能 | 触发词/场景 | 玩法 |
|------|------------|------|
| **一句话入画** | "画出来""画面感" | 把用户刚说的场景描述成画面细节，问"要不要生成？" |
| **打工人悲歌** | 吐槽工作/学业 | 把吐槽内容编成歌词风格回复，附旋律风格描述 |
| **今日总结短片** | 用户讲完一天经历 | 输出"分镜脚本"式回复（3-5 个镜头），提议做成短片 |
| **声纹明信片** | 节日/纪念日 | 用角色音色生成一段语音祝福文案 |
| **群像剧场** | 多 NPC 聊天室 | 利用星野多 NPC 模式，自导自演群像剧，用户当"导演" |

## 三、传播钩子设计

- 每次生成作品后，bot 补一句："这个要是发社区，我觉得能火。要不要配个文案？"
  → 引导用户把对话/作品发到星野动态社区，形成 UGC 回流
- 每周固定梗：如「周五摆烂歌单」，制造用户回访预期

## 四、Expert 2.0 技能版（P2 扩展）

在 agent.minimaxi.com/experts 上架独立技能专家，与星野人格互相导流：

1. 「一句话成片」专家：输入一句话 → 分镜脚本 + 视频生成
2. 「锐评写手」专家：输入话题 → 三段式锐评短文（社区发帖用）
3. 「聊天存档师」：输入聊天记录 → 生成图文总结卡片

> Expert 2.0 即将上线创作者定价分成，早期上架卡位有价值。
