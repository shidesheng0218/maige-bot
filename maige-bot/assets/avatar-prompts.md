# 形象生成提示词

> 星野支持上传图片 + 描述词生成动漫风头像（最多 18 张参考图）。
> 也可用 MiniMax 图像生成先产出概念图，挑满意的喂给星野。
> 三套风格对应三种人设气质，建议每套生成 4-6 张候选再定稿。

## 方案一：赛博信号体（推荐，贴合"住在信号里"的设定）

```
二次元风格，少年感角色，半透明的全息投影质感，身体边缘有轻微的
数据流 glitch 效果，短发带一撮蓝色挑染，穿着宽松的连帽衫，
耳机挂在脖子上，表情是带点痞气的微笑，眼神灵动，
背景是深蓝色数字空间，漂浮着发光的数据碎片，
赛博朋克配色（蓝紫渐变），光影通透，高完成度插画
```

## 方案二：温暖邻家系（偏树洞气质）

```
二次元风格，温暖治愈系少年，柔和的晨光打在脸上，
浅棕色短发，圆框眼镜推到头顶，毛衣袖口盖住半个手掌，
怀里抱着一杯热饮，笑容温暖带点狡黠，
背景是暖色调的房间角落，书架和绿植虚化，
日系插画质感，柔和光影，细腻笔触
```

## 方案三：抽象符号体（辨识度最高，适合极简头像）

```
极简设计，一个由信号波纹构成的拟人化小精灵，
圆形头部有天线，身体是流动的蓝紫色能量体，
只有简单的表情符号式五官，可爱搞怪，
纯色背景，扁平化设计，memphis 风格配色，
适合作为头像和表情包延展
```

## 选稿标准

- 缩略图辨识度：缩到 64px 还能认出轮廓（方案三天然占优）
- 表情包延展性：五官简洁的形象更容易二创表情包
- 人设贴合度：毒舌梗王配痞气，树洞配温暖，创作搭子配赛博感
